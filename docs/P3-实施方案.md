## 已定的决策（含 Nova 补充）

### 1. 托盘库与生命周期（Nova 补充）

- 用 `tray-icon 0.26`（§8 已核对：与现在的 winit 0.30 兼容），不引额外框架。
- **必须在主线程、事件循环启动之后创建**（win32 消息循环要求），图标句柄要长期持有，不能每帧新建。
- 托盘事件（左键点击／右键菜单）通过它自带的 channel 回收：在 `App::ui()` 里每帧 drain 一次，
  并配合 `request_repaint_after(300ms)` 的常态节流保证能及时收到（不额外开线程）。
- 图标：从现有的矢量标记（顶栏那个 L 方块）生成 16×16 / 32×32 两档位图，**不新增图片素材**
  （P1 已经把 PNG 素材全部删掉了，保持这条线）。

### 2. 托盘菜单项（Nova 补充）

| 菜单项 | 行为 |
|---|---|
| 显示 / 隐藏面板 | 切换控制面板窗口的可见性 |
| 显示全部卡片 | 等价面板里的「按今日展示」 |
| 隐藏全部卡片 | 等价面板里的「隐藏全部卡片」 |
| 退出 Lexideck | 真退出（面板里现有的 5 秒二次确认沿用） |

**为什么托盘必须有「显示面板」**：卡片切到「置顶＋鼠标穿透」时点不到，面板是唯一恢复通道；
如果面板被关进托盘又拿不出来，就等于把自己锁死。这条在 §6.5 与面板里的红框警告是同一件事。

### 3. 关闭窗口的行为（Nova 补充）

- 新增设置项 `close_action = tray | exit`，**默认 `tray`**（§6.5）。
- 实现上：面板的 ✕ 走 **隐藏窗口**（`ViewportCommand::Visible(false)`）而不是"关掉"——
  eframe 在窗口全关时会直接退进程，必须用 hide。卡片窗口继续留在桌面上。
- 真退出只有两条路：托盘菜单「退出」、或设置成 `exit` 后点 ✕（两条都走现有的二次确认）。

### 4. 开机自启动（Nova 补充）

- 写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `Lexideck`，数据 = 带引号的 exe 全路径。
  用 `windows-sys`（winit 已经带进依赖树，不算新增第三方）直接调 `RegSetValueExW` / `RegQueryValueExW`，
  保持 §8"不引第三方依赖"的风格。
- **面板显示的状态必须来自读注册表，而不是来自设置文件**：
  - 读不到 → 显示"未开启"；
  - 读到的路径 ≠ 当前 exe 路径（exe 挪过目录）→ 显示"已开启，但指向旧位置"，并给一个「重写」按钮；
  - 被任务管理器禁用（Run 项还在但被禁用）检测不到，文案不承诺"一定生效"（§8 已记这条局限）。
- 关掉开关 = 删掉该项（同时把 `设置.txt` 里的值写成 `off`，文件与注册表以注册表为准对账）。

### 5. 单实例（Nova 补充）

- 启动时 `CreateMutexW` 建一个 **`Local\Lexideck.SingleInstance`**（用 Local\ 不用 Global\：免管理员、
  免跨会话权限问题）。已存在 → 说明另有一个实例在跑。
- 唤前台的靠谱做法：第二个实例 **`FindWindowW` 找到已有主窗口 → `PostMessage` 一个自定义消息 →
  由已有实例自己调 `ShowWindow` + `SetForegroundWindow`**。不要让第二个实例直接 SetForegroundWindow
  —— Windows 会拦截后台进程抢前台，由收消息的进程自己做才稳。
- 已有实例收到消息后：若面板在托盘里 → 先显示；然后前置。处理完第二个实例自己退出（返回 0）。

### 6. 关于页（Nova 补充）

一个小块（不弹独立窗口）：软件名 + 版本（`env!("CARGO_PKG_VERSION")`，别写死）+ GitHub 地址 +
一句"免安装绿色版：设置、主库、状态都在 exe 同目录，整个文件夹拷走就带走全部状态"。

## 风险 / 待实机确认

- **托盘图标在教室一体机上可能被管理策略挡住**（§10 已列）。到教室第一件事就是看托盘在不在；
  如果不可用，"关闭窗口 = 驻留托盘"必须能退回"关闭 = 退出"（本来就是设置项，不会把自己锁死）。
- **未签名 exe**：别人机器上首次运行会弹"未知发布者"。要不要签名、要不要改成静态链接 CRT
  （免装 MSVC 运行库），等他在一体机上试过一次再定。
- 触摸手势、屏缩放 ≠ 100%、多显示器下的坐标，仍然只能在实机验（P2 遗留）。

## 注意（前两轮踩过的坑）

- 构建前先 `echo $CARGO_TARGET_DIR`，非空就 `unset`。
- 测数据**绝不写进** `target/debug/设置.txt`（那是他实际运行的配置）；验证一律在隔离副本里跑。
- 自动化点窗口：**窗口刚启动后的第一次点击只会激活窗口**，要点两次；控件坐标按源码布局常量算，
  别从裁剪图上目测。
- 两行文字的块要用确定高度的盒子，别用会吃掉整块高度的竖向容器。

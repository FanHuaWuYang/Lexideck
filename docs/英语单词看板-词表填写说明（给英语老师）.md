# 英语单词看板 · 使用与词表说明（给英语老师）

这个说明写给英语老师看，不需要任何电脑知识，大约 5 分钟就能看完。

---

## 一、它是做什么的

它由两部分组成：

- **控制面板**：您唯一需要操作的地方——导入词表、排展示时间、调字号、换主题。
- **桌面卡片**：显示单词的小卡片，由面板统一管。卡片只负责显示，没有任何按钮。

卡片默认**贴在最底层**：全屏放 PPT 时会被盖住，所以不会挡住其他课的 PPT；课间或回到桌面时才看得到。需要常显时可以切成「置顶」，再配合「鼠标穿透」，这样卡片看得见、但点击照样落到 PPT 上。

数据全部存在本机文件夹里，不上网也能用，免安装。

---

## 二、第一次打开

1. 双击 `Lexideck.exe`。会打开「控制面板」，默认停在「词表」页。
2. 如果 Windows 提示「未知发布者」，点「更多信息 → 仍要运行」即可（程序没有做数字签名，属于正常提示）。
3. 关掉面板不会退出程序——默认收进右下角托盘，卡片继续显示。要彻底退出：设置页「退出 Lexideck」。

---

## 三、词表从哪来（两种方式）

### 方式 A：用现成的预置词表

随程序带了三份：**高中必备 3500 词 → 四级增补 → 六级增补**。
按这个顺序依次导入即可——增补册里只有新增的词，词库会自动叠加，不会重复。
（如果只要高考范围，只导第一份就够。）

### 方式 B：让 AI 帮您生成（按单元、按主题出词时最省事）

把随附的 `skill-词表生成.md` **一起发给 AI**，然后附上一句：

> 请阅读这份 skill，按它的规范帮我生成词表：人教版必修一 Unit 2 的核心词，每个词带词性和中文释义，再配 2 条短语，排在下个月 3 日到 9 日展示。

AI 会输出一个 `.json` 文件。把它存到电脑上（放桌面就行），下一步导入。

---

## 四、把词表导进看板（三步）

1. 打开控制面板，顶栏停在「词表」页，点右上角 **「导入词表…」**。
2. 选中那个 `.json` 文件，点「打开」。
3. 如果词库里已经有同名的词，程序会逐条问您：
   **跳过 / 替换 / 剩下的都跳过 / 剩下的都替换**——按需要选就行。
   导入完成后会显示一份清单：新增多少、替换多少、跳过多少。

> 导入是「并入」：不会删掉库里原有的词，只是把新词加进去、把您选择替换的词更新掉。

---

## 五、让词在某几天上屏（展示时间）

词在库里，不等于会自动出现在屏幕上——**要排了展示时间才会上屏**。

- 排展示时间最方便的办法：让 AI 生成词表时一起排好（skill 里有写法），或者单独生成一份只含展示时间的文件再导入一次。
- **一天 3~5 个词最合适**。排到 8 个以上，学生的注意力就跟不上了；排十几个基本白排。
- 同一天排多了：屏幕放不下的会**按顺序截断**，不会挤成一团。
- 当天没排期：屏幕就是空白，不会接着显示昨天那批。
- 想临时手动展示几个词（课前热身、听写前过词）：「词表」页勾选 → 点右下角 **「立即展示」**；想回到按日期自动展示，点 **「按今日展示」**。

「策略」页能看到：今天上屏几个、被永久关闭的有哪些、未来排期、已经结束的排期。

## 六、卡片怎么显示

| 想做的事 | 在哪调 |
|---|---|
| 不让卡片挡住 PPT | 默认就是「置底」，不用动 |
| 让卡片常显在 PPT 上方 | 设置页 → 卡片层级 → **置顶** |
| 常显又不想挡住点击 | 设置页 → 鼠标穿透 → **开**（开启后卡片点不到，恢复入口只有控制面板；面板里有「关闭穿透」「隐藏全部卡片」） |
| 马上收掉全部卡片 | 底部 **「隐藏全部卡片」**，或托盘右键菜单 |
| 把卡片叫回来 | 底部「按今日展示」，或托盘菜单「显示全部卡片」 |
| 字太小 / 太大 | 「卡片」页的「字号档位」用 − / + 调；旁边有「复位 0.70」 |
| 换配色 | 设置页 → 主题（纯白 / 浅青 / 黄黑） |

卡片位置由平铺规则决定（从右上角起、往下排、排满一列向左）。临时挡到东西时可以直接把卡片拖开，下次重排会回到原位。

## 七、关窗口、托盘、开机自启

- **关闭窗口时**（设置页可选）：
  - **驻留托盘（默认）**：卡片不掉，点右下角托盘图标（可能在 `^` 折叠区），或再双击一次程序，面板就回来了。
  - **直接退出**：关面板就等于退出程序，需要在 5 秒内点两次 ✕。
- **开机自启动**：设置页一个开关，开了以后登录电脑就自动打开，不用管理员权限。
- **单实例**：同一个程序只会开一个窗口——重复双击不会开出第二个，只会把已有窗口叫到前面。
- **界面语言**：设置页最上方「界面语言」可以在中文 / English 之间切换，点了立即生效。

## 八、常见问题

**Q：导入时提示「文件格式不对」怎么办？**
A：这份文件不会被导入，词库保持原样，弹窗里会列出具体哪一条有问题。把提示发给帮您生成词表的 AI，让它按提示修好再导入。不要自己用 Word 改 `.json` 文件。

**Q：词导入成功了，但屏幕上没有卡片？**
A：按顺序检查三件事：
1. 「策略」页「今天上屏」是不是 0（今天没排展示时间）；
2. 这个词是不是被永久关闭了（「策略」页的开关）；
3. 是不是点过「隐藏全部卡片」（底部按钮或托盘菜单恢复）。

**Q：发现某个词写错了 / 想改释义？**
A：控制面板里不直接改内容。改那份 `.json` 文件后重新导入，同名词条会问您是否替换。

**Q：能显示音标吗？**
A：当前版本不显示音标。卡片上可以有：单词 / 短语、词性、中文释义、短语搭配、例句、备注。

**Q：数据存在哪？需要备份吗？**
A：都在程序所在文件夹里：`lexideck.json`（词库）、`设置.txt`（设置）、`状态.json`（策略开关）。每周把整个文件夹复制一份到 U 盘就是完整备份。**这三个文件不要手动改。**

**Q：换一台电脑怎么搬？**
A：把整个程序文件夹拷过去即可，免安装、不用重装。

---

## 九、不要做的三件事

1. **不要用 Word / 写字板编辑 `.json` 文件**——会自动改掉引号，文件就坏了。要改就改源文件后重新导入。
2. **不要手动编辑 `lexideck.json` / `状态.json`**——改坏会导致程序读不懂，宁可重新导入。
3. **不要单独挪走数据文件**——整个文件夹一起搬没问题，只把 `lexideck.json` 拿出去，程序就找不到词库了。

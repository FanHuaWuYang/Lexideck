# 英语单词看板 · 词表填写说明

这个说明是给**英语老师**看的，里面不需要任何电脑知识。全部内容大概 5 分钟能看完，看完了您就会用。

---

## 一、这个东西是干什么的

它是一个**小小的窗口**，可以一直显示在教室大屏的最上层。窗口里显示您准备好的一批单词、短语或句子，您可以用**手指**点"上一个 / 下一个"来切换，也可以让它每隔几秒自动换一条。

窗口可以：
- 用一根手指**按住拖动**到屏幕任意位置（比如拖到右下角，不挡板书）
- 点 **A+ / A-** 把字放大缩小（后排看不清就点 A+）
- 点 **隐藏** 让它消失，按 **Ctrl + Alt + H** 再叫出来
- 随时读取您改过的词表，**不需要重开程序**

---

## 二、怎么改内容（三步）

1. 打开程序所在的文件夹，找到一个叫 **`词表.txt`** 的文件。
2. **双击**它（会用"记事本"打开），改成您想要的内容，然后按 **Ctrl + S** 保存。
3. 回到程序，**两秒后屏幕上的内容自动变成新的**。（什么都不用点）

> 如果文件夹里没有 `词表.txt`，您可以自己新建一个：在文件夹空白处**右键 → 新建 → 文本文档**，把文件名改成 `词表.txt`（注意：连扩展名 `.txt` 一起写）。

> ⚠️ 千万**不要改文件名**，也**不要删掉 `.txt`**。程序只会读这个文件夹里以 `.txt` 结尾的文件。

---

## 三、内容怎么写（看三个例子就够了）

### 例子 1：最简单的——只写单词

一行一个单词，写完就好：

```
abandon
benefit
climate
contribute
```

这样每个单词就是一张卡片，屏幕上显示大写的单词，没有中文和例句。**这是最不容易出错、也最快的方式**，适合课前热身、听写前的快速过词。

### 例子 2：完整的单词卡——带音标、词性和中文

```
abandon
音标: /əˈbændən/
词性: v.
释义: 抛弃，放弃；遗弃
例句: He abandoned his car and walked home.
例句翻译: 他弃车步行回家。

benefit
音标: /ˈbenɪfɪt/
词性: n. / v.
释义: 好处；受益
例句: Regular exercise has many benefits.
例句翻译: 经常锻炼有很多好处。
```

**单词和它的说明之间，不要空行。不同的单词之间，用一个空行隔开。**

### 例子 3：讲句子（讲语法点的时候用）

```
Good habits are hard to form but easy to live with.
翻译: 好习惯难于养成，却易于相伴一生。
语法: be hard to do 结构，动词不定式作状语

What matters most is not speed, but direction.
翻译: 最重要的不是速度，而是方向。
语法: what 引导的主语从句 + not...but... 并列
```

整句话放在第一行，下面写"翻译"和"语法"。

### 例子 4：讲短语 / 固定搭配

```
take part in
释义: 参加，参与
例句: She took part in the speech contest.
例句翻译: 她参加了演讲比赛。
备注: 后接名词或动名词，不用于被动语态
```

## 四、可以写哪些"补充信息"

下面这些词可以随意组合，**写几个就显示几个，全都不写也能用**。

| 您要写的话 | 可以写成（都行，任选一种） | 显示效果 |
|---|---|---|
| 音标 | `音标` / `发音` / `ph` / `ipa` | 单词下面小字 |
| 词性 | `词性` / `词类` / `pos` | 和音标同一行 |
| 中文意思 | `释义` / `意思` / `中文` / `含义` / `翻译` | 中等大小的黄色字 |
| 例句 | `例句` / `例子` / `example` | 灰色小字 |
| 例句的翻译 | `例句翻译` / `例译` | 更小的灰字 |
| 讲语法 | `语法` / `语法点` / `知识点` | 带色块标签 |
| 随便备注 | `备注` / `说明` / `注释` / `note` | 最下面小字 |

**格式只有一条规矩：** 先写上面的词，然后写一个**冒号**（中文的 `：` 或英文的 `:` 都行），再写内容。

```
释义：抛弃，放弃
释义: 抛弃，放弃
释义 抛弃，放弃          ← 忘了写冒号也没关系，照样认得出来
```

## 五、十条注意事项（都是最容易踩的坑）

1. **不要写引号、括号、逗号分隔的列表。** 这些是给电脑"程序文件"用的写法，我们这里不需要。直接写中文就行。
2. **一行只写一件事。** 不要把音标和释义写在同一个"释义"行里。
3. **不同的单词之间空一行**（或者单独写一行 `---`），这样程序才知道哪里是一条的结束。
4. **"释义"可以写多个意思**，用中文逗号或分号隔开，例如：`抛弃，放弃；遗弃`。
5. **中文标点符号没关系**，中文冒号 `：`、中文逗号 `，` 都能正常显示。
6. **绝对不要用 Word 编辑这个文件。** Word 会把直引号变成弯引号、会加入很多看不见的格式。请一定用**记事本**。
7. **保存的时候不用管编码**。记事本默认保存的就是对的；即使保存成了"ANSI"，程序也能读出来，不会乱码。
8. **文件写错了也不会让程序坏掉。** 哪一行写得不对，程序就只把那一行原样显示出来，并在窗口上方提示"第几行好像有问题"，其他内容照常显示。**上课时不用担心把屏幕搞黑。**
9. **一条内容字数别太多。** 整句建议 15 个词以内，超过 3 行屏幕会自动缩小字号。
10. **想准备多份词表**（比如 Unit1、Unit2、听写专用），就建多个文件，放在程序旁边同一个文件夹里，名字随便取，比如 `Unit1.txt`、`Unit2.txt`。程序里点"词表"那个按钮就能切换。

## 六、常见问题

**Q：音标怎么打出来？**
A：可以不写。真要写，用输入法打不出那些符号时，最简单的办法是**从课本电子版或词典里复制粘贴**。也可以只写"重音在哪"，比如 `abandon (重音在第二音节)`。

**Q：我改完文件，屏幕上没变化？**
A：检查两件事：① 有没有按 **Ctrl + S** 保存（记事本里文件标题栏的"*"号消失了才算保存成功）；② 词表文件名是不是 `词表.txt`，有没有被改成 `.txt.txt`。
还是没反应，就点程序面板上的 **"重新读取"**。

**Q：屏幕上的中文变成了一堆问号或者方块？**
A：说明保存的编码不对。用记事本打开 `词表.txt`，**另存为**，在下面的"编码"下拉框里选 **UTF-8**，覆盖保存即可。

**Q：显示的字太小 / 太大？**
A：点面板上的 **A+** 或 **A-**。每次变化 20%，调到合适为止。设置会被记住，下次打开还是这么大。

**Q：上课的时候怎么快速把它去掉？**
A：按 **Ctrl + Alt + H** 一下就隐藏了（再按一下回来）。或者点面板上的"隐藏"大按钮。
**放在哪里最不挡事**：拖到屏幕**右下角**。

**Q：我不想让它显示句子，只想快速过单词？**
A：面板上的"显示"那一项选"只有单词"，句子就会暂时被过滤掉。

**Q：能不能让它自己一条一条自动换？**
A：可以。点"自动切换"打开，再选间隔（15 秒 / 30 秒 / 60 秒）。您手动点"下一个"的时候会自动重新计时，不会跳得太快。

**Q：我想让它显示一个英文单词的两种拼写（英式/美式）？**
A：写在同一个"释义"行里就行：`释义: 颜色（英式 colour）`。

**Q：能不能加发音？**
A：目前不能。教室的音响经常被别的软件占用，所以这个功能没有做。

## 七、一页示例（可以直接复制）

下面整段可以直接复制进 `词表.txt`，改成您自己的内容：

```
abandon
音标: /əˈbændən/
词性: v.
释义: 抛弃，放弃；遗弃
例句: He abandoned his car and walked home.
例句翻译: 他弃车步行回家。

contribute
音标: /kənˈtrɪbjuːt/
词性: v.
释义: 贡献；投稿；促成
例句: Everyone can contribute to the environment.
例句翻译: 每个人都能为环境出一份力。

take part in
释义: 参加，参与
例句: She took part in the speech contest.
例句翻译: 她参加了演讲比赛。
备注: 后接名词或动名词

It is not what you have but what you do that counts.
翻译: 重要的不是你有什么，而是你做了什么。
语法: 强调句 It is ... that ... 结构

climb
benefit
climate
```

（最后三个词故意只写单词，用来演示"也可以完全不写说明"。）

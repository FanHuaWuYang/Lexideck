# 英语单词看板 · 词表准备与导入说明

这份说明是给**英语老师**看的，不需要任何电脑知识，5 分钟能读完。读完了您就会用。

---

## 一、这个东西是干什么的

它由两部分组成：

- **控制面板**（一个窗口）：管理词表、选择今天要展示的词、调整字号和外观。
- **单词卡片**（可以有很多张）：平铺在桌面右侧，每张显示一个单词或短语。上课时它们安静地待在桌面上，
  **不会挡住 PPT 的点击**（默认在最底层）。

您把要教的词整理成一份**词表文件**，导入一次，程序就记住了。之后每天：

1. 打开程序（或让电脑开机自动打开）；
2. 当天该展示的词会**自动出现在桌面上**；
3. 想临时加词/换词，在面板里勾选几个，点右下角「立即展示」。

---

## 二、词表从哪来（两步）

### 第一步：准备内容清单

不用自己拼格式。两种省事的做法：

**做法 A（推荐）**：把您想教的内容列给任何一个 AI 助手（比如常见的聊天 AI），请它**按仓库里的
`skill-词表生成.md` 规范生成一份 JSON 词表**。您只要说清楚：要哪些单词/短语/例句、要不要中文释义。
它会输出一个 `.json` 文件，保存下来即可。

**做法 B**：用随程序附带的《示例-词表.json》当模板——用**记事本**打开，把里面的词句**换成您的**，
**只改文字，别动括号、引号、逗号的位置**。改完保存。（结构一旦碰坏，导入时程序会一次列明哪里不对。）

> 词表文件里可以写：单词、词形变化、词性、中文释义、同根词、短语、例句、备注。
> 这些内容在卡片上各占一块，**不写的块不会显示**。

### 第二步：导入程序

1. 打开程序，点上方「**词表**」页；
2. 点「**导入词表…**」，选中您那份 `.json` 文件；
3. 导入完成后，底部会告诉您：新增几条、并入几条。**导入 = 并进已有的库**，不会把之前的内容弄丢；
   同一个词再次导入会用新内容更新它。

如果文件里有写错的地方，程序会**一次把全部问题列出来**（不会改坏已有内容），您改好再导一次即可。

## 三、想按日期自动上屏（可选）

如果希望「这周教 Unit 5、下周教 Unit 6」，可以让 AI 在词表里给每个词写上**日期段**
（从哪天到哪天展示）。这样：

- 当天在日期段内的词，**打开程序就自动上屏**；
- 没写日期段的词不会自动上屏，但可以随时在面板里勾选手动展示。

不写日期段也完全能用——那样就全靠手动勾选，适合随讲随选。

## 四、上课时最常用的几个操作

| 想做的事 | 怎么做 |
|---|---|
| 临时选几个词上屏 | 「词表」页勾选 → 右下角「立即展示」 |
| 让卡片全部消失 | 「设置」页「隐藏全部卡片」 |
| 让卡片回来 | 右下角「按今日展示」（或托盘图标右键菜单） |
| 字太小 | 「卡片」页点 **A＋**（每次加一档，调好会被记住） |
| 卡片挡住了想点的东西 | 默认在最底层不会挡；确需常显又不挡点击 → 设置页开「置顶＋鼠标穿透」 |
| 关掉面板 | 点右上 ✕＝**收进右下角托盘**（点托盘图标可唤回；把面板拖去不挡事的位置也行） |

> 托盘图标有时被 Windows 收进右下角的 **^ 折叠区**——点开折叠区把「Lexideck」拖出来即可常驻。
> 唤回面板的另一种办法：**再双击一次程序图标**。

## 五、常见问题

**Q：屏幕上的内容还是旧的？**
A：在别的电脑上改文件不会自动同步过来——**必须导入**（「词表」页 →「导入词表…」）。

**Q：导入时提示文件有问题？**
A：程序会把每一处问题列全（比如「第 5 条缺少释义」）。把出错的地方改好（或让 AI 改）再导入。
**已有内容不受影响**，不用怕。

**Q：中文显示成方块或问号？**
A：让 AI 生成词表时说明「用 UTF-8 编码」；如果仍然异常，把文件发给我来处理。

**Q：卡片位置乱了吗？**
A：卡片可以拖开临时让位；下一次有卡片增减或字号变化时，会**自动回到整齐的平铺位置**。

**Q：想准备好几份词表（比如 Unit1、Unit2）？**
A：生成多个 `.json` 文件，逐个导入即可。它们会并进同一个库（重复的词自动合并）。

---

*如果哪次上课出了意外、屏幕不见了：先找右下角托盘里的 Lexideck 图标；找不到就再双击一次程序；
再不行就重新打开程序——您导入过的内容都不会丢。*

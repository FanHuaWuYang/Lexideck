# 预置词表（词 + 短语，追加式三件套）

三份文件是**追加关系**：第一份打底，后两份只含「在上一档基础上新增」的内容。
按顺序依次导入即可叠加成完整词库（导入 = 并进主库，不会覆盖已有内容）。

|---|---|---|---|---|
| `高中必备3500词.json` | 7409 | 3980 | 3429 | 高中打底（单词 + 高中短语；补齐 107 个基础词） |
| `四级增补包.json` | 3142 | 1604 | 1538 | 在高中基础上**追加**：四级新增单词 + 四级短语 |

三份全导 = **12946 条**（6507 个单词 + 6439 条短语）。

- 只含「词头 + 词性 + 释义 + 固定搭配」；不含例句、备注；短语词性统一为 `phr.`
- **固定搭配**（2026-10-31 新增）：每词最多 3 条，用 `phrases` 字段挂在词条下，卡面会以小字显示，例如
  `prevent sb. from doing sth.`（阻止某人做某事）、`make sb. do sth.`（使某人做某事）、`be used to doing sth.`（习惯于做某事）
- 导入方式：面板「词表」页 → 导入词表 → 依次选择（顺序：高中 → 四级增补 → 六级增补）
- 只需要高中内容就只导第一份；要到四级就导前两份；要到六级三份都导

## 生成口径（2026-10-17 v2）

- 去重键：小写 + 合并空白 + 去尾部句点；**跨三份文件全局去重**（追加包只保留增量，三份互不重复）。
- 短语过滤：必须含空格、纯英文、长度 ≤ 46 字符；查不到中文释义的短语不收录
  （源文件里被截断的模板残片、错拼会被自然滤掉）。
- 释义清洗后最长 60 字符，括号配对修正。
- 面板内显示会按字母排序，与文件内顺序无关。
- 固定搭配去重：同词条内按小写 + 合并空白比较；每词最多 3 条，已有教材搭配优先，生成搭配只补空缺。

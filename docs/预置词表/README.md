## 生成口径（2026-10-17）

- 去重键：小写 + 合并空白 + 去尾部句点；跨级去重（后一级只保留增量）。
- 短语过滤：必须含空格、纯英文、长度 ≤ 46 字符；查不到中文释义的短语不收录。
- 释义补全顺序：教材原生 → 大学生必备网词组表 → ECDICT → FCE；释义清洗后最长 60 字符。
- 词条顺序沿用源文件顺序；面板内显示时会按字母排序，与文件顺序无关。

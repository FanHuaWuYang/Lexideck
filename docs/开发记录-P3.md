# P3a 开发记录（托盘驻留，2026-10-02）

P3 的第一件事：**托盘驻留 + 关闭窗口的行为**（设置项「关闭窗口时：驻留托盘 / 直接退出」）。
范围与决策见 `docs/P3-实施方案.md`；本文只记实际做了什么、踩到什么、怎么验的。

## 1 做了什么

- **托盘图标**：雾青圆角方块 + 白色「L」，逐像素画（不引图片素材），tooltip「Lexideck — 词卡看板控制面板」。
- **左键单击** = 显示 / 隐藏面板；**右键** = 打开菜单（显示/隐藏面板、显示全部卡片、隐藏全部卡片、退出 Lexideck）。
- **关闭行为**：默认「驻留托盘」——点 ✕ = 面板收进托盘（卡片照留在桌面）；设置里可切「直接退出」（沿用 5 秒二次确认）。
- **真退出三条路**（都用一个 `exiting` 标记绕过关闭拦截）：面板「退出」按钮 / 托盘菜单「退出」/ `exit` 模式点两次 ✕。
- 托盘建不起来时自动退回「关闭 = 退出」，不会出现"面板藏了却没处唤回"把自己锁死的情况。

## 2 两个跟"系统级模态"有关的关键决策

### 2.1 「收进托盘」不能用隐藏窗口，必须挪到屏幕外

eframe 0.36 对「不可见 / 最小化」窗口会走一条直接补画的旁路（为修 egui#5229 的 Windows 问题所加）。
那条路**没有登记事件循环上下文**，于是「新建窗口」（= 新词卡上屏、从托盘显示全部卡片）会被静默跳过，
egui 随即断言崩：`egui backend is implemented incorrectly - the user callback was never called`。

实测（带 PDB 的 backtrace + 临时给 eframe 源码插调试输出定位）：

- 复现：面板隐藏时，从托盘点「显示全部卡片」必崩；课堂上新词到点上屏同样会崩。
- 定位：调试输出 `[eframe-dbg] render_immediate_viewport ...: NO current event loop context`。
- 处置：**「收进托盘」= 把窗口挪到 (-32000,-32000)**。窗口仍是「可见」态，所有帧走正常路径；
  `reconcile_floats` 里补一条：窗口最小化时先不建新浮窗，等恢复的下一帧再补。
- 验证：隐藏状态下从托盘新建浮窗不再 panic；唤回时**精确回到原位** (60,360)。

### 2.2 托盘右键菜单从系统原生改成自绘

muda 的原生菜单走系统级模态 `TrackPopupMenu`：**点完菜单项之后 winit 主循环会"冻住"**
（进程活着、消息泵在转、CPU 0%、一帧不跑，连 posted 的 WM_CLOSE 都不派发）。
winit 源码里对系统菜单冻结用的招数是给窗口发一条假鼠标移动，心跳线程照做后的对照实验：

- **不唤醒**：菜单能正常关，但应用"睡着"不执行动作 —— 7/7 全挂；
- **无脑唤醒**：会把原生菜单自己的模态循环打断，约 1/2 概率卡成「点不动的幽灵菜单」（点条目没反应、菜单不关）。

两难，且都是原生死路。最终方案：**整个弃用原生菜单** —— 右键改成自绘菜单
（`src/menu.rs`，就是一个普通即时视口，没有模态循环），从根上消灭这类问题；
样式还能和面板共用同一套 Theme。实测两轮 × 7 次菜单交互：**0 卡死、0 冻结**。
心跳（250ms；怀疑冻住时发一条假鼠标移动）保留为**通用保险**——系统文件对话框等其它模态路径
也可能触发"睡死"，留着它冻住也能自愈。

## 3 面板复审发现并修掉的两个缺陷（慕言真机反馈）

### 3.1 托盘隐藏面板后卡片变小、跑位

- 现象：卡片从 448×309 变成 336×232，位置从 (1444,34) 跑到 (1083,25)。
- 根因：面板挪到屏外后，系统把它算成「**最近的**显示器」（= 左边那块 1440×1080），
  屏幕系数从 1.0 掉到 0.75，平铺锚点也跟着换屏。
- 修法：屏幕尺寸「面板可见时读实时值并记住，收进托盘时用记住的值」；三个读取点统一走它。
- 验证：隐藏后卡片稳定在 448×309 @(1444,34)，唤回后照旧。

### 3.2 顶栏 ✕ / 最小化按钮悬浮时闪灰

- 现象：鼠标悬浮上去，按钮背景先闪一两帧深灰再到目标色（"会闪烁"）。
- 根因：淡入用了 `mix(Color32::TRANSPARENT, 色, t)` —— alpha 被一起插值、再预乘一次，
  过渡中段算出的中间色发灰。同点位像素采样实证：`BCBDBD → D1D2D2 → F9FAFB`。
- 修法：三处同一模式（顶栏按钮 ×2、卡片区按钮 ×1）全部改成 `色.gamma_multiply(t)`
  （颜色连同 alpha 等比缩 = 真正的淡入）。
- 验证：同点位采样变成 `F5F7F8 → F8F9FA → F9FAFB`，全程浅色、无灰帧。

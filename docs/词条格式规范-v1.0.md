# 词条格式规范 v1.0

> **状态**：定稿（2026-10-01）。取代 `词条格式规范-草稿.md`（v0.4，那份只作历史记录）。
> 本文是 **JSON 字段与卡片版式的权威规范**；设计意图见根目录 `Lexideck.md`（v1.0）。
> 字段键一律用**全英文**，方便 AI 生成器和校验器处理。

---

## 一、文件形态

一个 `.json` 文件 = 一本「词卡册」，里面有两个部分：

| 部分 | 内容 | 必填 |
|---|---|---|
| `words` | 词条本体 | 两个部分至少有一个 |
| `display_time` | 每个词的展示日期段 | 两个部分至少有一个 |

- 编码 **UTF-8**，顶层 `version` 必填（当前 = 1）。
- **导入 = 并入主库**。主库是唯一事实来源，放在 exe 同目录；被导入的文件导入后不再被引用。
- 两个部分**分开导入、顺序固定**：先词条，再展示时间。所以一个文件可以只写 `words`，也可以只写 `display_time`。

```json
{
  "version": 1,
  "deck_name": "Unit 1 核心词",
  "words": [ { "...词条..." : "" } ],
  "display_time": [ { "word": "seek", "ranges": [ { "from": "2026-10-06", "to": "2026-10-12" } ] } ]
}
```

`deck_name` 可选，只是这本册子的标签，会在「展示策略管理」里显示成"来源文件"。

## 二、词条（words）

### 2.1 字段表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `word` | 字符串 | ✅ | 主体（单词 / 短语 / 整句皆可）。**永远显示，不能隐藏** |
| `senses` | 数组 `{pos?, meaning}` | ✅ | 词性 + 释义，至少一条；**一行一义项** |
| `forms.past` | 字符串 | | 过去式 |
| `forms.past_participle` | 字符串 | | 过去分词 |
| `derivations` | 数组 `{word, senses}` | | **同根词变形**（新）。每个同根词带自己的词性与词义 |
| `phrases` | 数组 `{text, meaning?}` | | 语法 / 固定搭配 |
| `sentences` | 数组 `{en, zh?}` | | 例句 / 俗语；中文翻译可选 |
| `note` | 字符串 | | **备注**（新）。任意内容 |
| `hide` | 数组 `<区块名>` | | 关闭默认展示的区块，见 2.2 |

### 2.2 `hide`：关闭默认展示

- 写了但不想上卡片的区块，把区块名放进 `hide`。
- 可取值：`senses`、`forms`、`derivations`、`phrases`、`sentences`、`note`。
- **`word` 不在其中**——单词本体不支持隐藏。
- 关掉只是"不进卡片"：内容**完整保留在库里**，「词表管理」展开时仍然看得到，随时可以再打开。
- 省略 `hide` 或给空数组 = 所有写了的区块都显示。

### 2.3 完整示例

```json
{
  "word": "seek",
  "senses": [
    { "pos": "v.", "meaning": "寻找；寻求；试图" },
    { "pos": "n.", "meaning": "（古）搜寻" }
  ],
  "forms": { "past": "sought", "past_participle": "sought" },
  "derivations": [
    { "word": "seeker", "senses": [ { "pos": "n.", "meaning": "探索者；追求者" } ] }
  ],
  "phrases": [
    { "text": "seek to do sth.", "meaning": "试图做某事" },
    { "text": "seek out", "meaning": "找出；搜寻到" }
  ],
  "sentences": [
    { "en": "She sought advice from her teacher.", "zh": "她向老师寻求建议。" }
  ],
  "note": "写作高频，注意 sought 的拼写",
  "hide": ["note"]
}
```

最简示例（只有主体 + 释义）：

```json
{ "word": "Practice makes perfect.", "senses": [ { "meaning": "熟能生巧。" } ] }
```

## 三、展示时间（display_time）

```json
{
  "word": "seek",
  "ranges": [ { "from": "2026-10-06", "to": "2026-10-12" } ],
  "hide": ["sentences"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `word` | 字符串 | ✅ | 必须能在主库里找到（`word` 不区分大小写）；找不到就弹窗 |
| `ranges` | 数组 `{from, to}` | ✅ | 至少一段；`from` ≤ `to`；**允许多段、允许与他人重叠** |
| `hide` | 数组 `<区块名>` | | 该段时间里的显隐**覆盖**，取值同 2.2 |

规则：

- 日期是**物理天**（本机本地日期），格式 `YYYY-MM-DD`。
- **同一天有多段生效 → 全部显示**，屏幕放不下就按顺序截断。
- **当天没有任何段生效 → 屏幕空白**。
- `hide` 覆盖只在对应的日期段内生效，**不改动词条本身**；导入时若出现覆盖，弹窗问是否采用。

## 四、校验与导入

### 4.1 格式校验（只查格式，不查词典）

必查项：

- 顶层 `version` 存在且为 1
- `word` 非空、不是乱码
- `senses` 至少一条，且每条 `meaning` 非空
- 日期是合法 `YYYY-MM-DD`，`from` ≤ `to`
- `hide` 里的名字只能是 2.2 列的六个
- 字段类型不对（比如 `phrases` 写成了字符串）直接判错

**不做词典校验**——一体机不联网。像 `seekk` 这种拼写错误，程序不负责拦。

### 4.2 冲突与合并

| 内容 | 唯一键 |
|---|---|
| 词条 | `word`（不区分大小写） |
| 展示时间 | `word` + 日期段 |

- 键相同、内容也相同 → 重复，静默并入。
- 键相同、内容不同 → 冲突，**弹窗**：跳过 / 替换 / 全部跳过 / 全部替换。
- 展示时间引用了主库里没有的词 → **逐个弹窗**，弹窗带「剩下的都跳过」。
- 导入结束必须给**结果清单**：新增 N 条、更新 N 条、跳过 N 条、未匹配哪些词。

### 4.3 出错时

解析失败**绝不动主库**，只在面板上安静提示。绝不出现白屏或空词库。

## 五、卡片版式

版式已冻结。基准宽 **640（逻辑单位）**，高度随内容自然收紧。

```
┌──────────────────────────────────────┬──┐
│ ① 词头·释义（必有）                  │  │
│    seek  sought sought ← 变形小字    │色│
│    v. 寻找；寻求；试图               │条│
├──────────────────────────────────────┤  │  ← 写了且未 hide 才有
│ ② 同根词  seeker  n. 探索者          │  │
├──────────────────────────────────────┤  │
│ ③ 短语                               │  │
├──────────────────────────────────────┤ 2.2%
│ ④ 例句  英文（大）＋译文（小一号）    │  │
├──────────────────────────────────────┤  │
│ ⑤ 备注（小字，通常不配置）           │  │
└──────────────────────────────────────┴──┘
```

- 区块自上而下堆叠，**写了并且没被 hide 才出现**，没写就不出现也不留空。
- 字号（640 宽下）：单词 60（长句自动降号）｜变形小字 30 ｜同根词 26 ｜词性+释义 28
  ｜短语 26 ｜例句 26 ｜译文 22 ｜备注 20
- 区块间距上下约 8–14px，行距 1.15–1.2。
- 右侧色条宽 = 640 × 2.2% ≈ 14px，颜色随主题（默认 #668D82）。
- **缩放**：卡片宽度 = 屏幕宽度 × 固定比例（**屏占比一致**），不是写死像素；比例在面板里可调。
- **溢出**：词头单行**逐档降字号**（60 → 48 → 40 → 34），降到最小档仍放不下才**折成两行**（折行字号 38，
  见 `src/card.rs` 的 `WORD` / `WORD_WRAP`）。这是 9-25 冻结的版式，规范以实现为准。
  其余行（释义/短语/例句）不降档、不截断，靠换行跟着内容长高。

### 内容上限（建议值）

| 区 | 上限（超了降档缩字，不丢内容）|
|---|---|
| 释义 `senses` | ≤ 3 行，每行 ≤ 24 字 |
| 同根词 `derivations` | ≤ 2 条 |
| 短语 `phrases` | ≤ 3 条（英文 ≤ 24 字符，中文 ≤ 16 字）|
| 例句 `sentences` | ≤ 2 条（英文 ≤ 50 字符，中文 ≤ 32 字）|
| 备注 `note` | 一句话以内 |

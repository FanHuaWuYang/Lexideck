## 一、文件形态

一个 `.json` 文件 = 一本「词卡册」。放在 exe 同目录，程序查找顺序：

`词表.json` → `词表.txt`（旧格式，过渡期保留）→ 内置示例

编码 UTF-8。

```json
{
  "version": 1,
  "deck_name": "Unit 1 核心词",
  "words": [ { "……词条……": "" } ]
}
```

## 二、词条字段（每个部分都可省略 → 省略就不显示）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `word` | 字符串 | ✅ | 主体（单词 / 短语 / 整句皆可） |
| `senses` | 数组 `{pos?, meaning}` | ✅ | 词性 + 释义；**一行一义项**，紧贴单词下方 |
| `forms.emphasize` | 布尔 | | **是否显示**过去式 / 过去分词；`true` 时以小字号跟在单词后面 |
| `forms.past` / `forms.past_participle` | 字符串 | | 过去式 / 过去分词 |
| `phrases` | 数组 `{text, meaning?}` | | 相关短语（不写 → 没有「短语」区块） |
| `sentences` | 数组 `{en, zh?}` | | 相关优质句子（不写 → 没有「例句」区块） |
| `display_days` | 整数 | | 计划展示天数（可选；省略 = 1） |

完整示例（不规则动词，变形显示）：

```json
{
  "word": "seek",
  "senses": [ { "pos": "v.", "meaning": "寻找；寻求；试图" } ],
  "forms": { "emphasize": true, "past": "sought", "past_participle": "sought" },
  "phrases": [
    { "text": "seek to do sth.", "meaning": "试图做某事" },
    { "text": "seek out", "meaning": "找出；搜寻到" }
  ],
  "sentences": [
    { "en": "She sought advice from her teacher.", "zh": "她向老师寻求建议。" }
  ]
}
```

最简示例（只有主体 + 释义）：

```json
{ "word": "Practice makes perfect.", "senses": [ { "meaning": "熟能生巧。" } ] }
```

## 三、版式（基准宽 640 · 高度随内容）

区块自上而下堆叠，**宽度基准 640，高度 = 内容自然收紧**；程序整体等比缩放到窗口尺寸（宽度基准 × k），任意分辨率外观一致。

```
┌──────────────────────────────────────┬──┐
│ ① 词头·释义（必有）                  │  │
│    seek  sought sought ← 变形小字    │色│
│    v. 寻找；寻求；试图               │条│
├──────────────────────────────────────┤  │  ← 写了 phrases 才有这一块
│ ② 短语                               │  │
├──────────────────────────────────────┤ 2.2%
│ ③ 例句  英文（大）＋译文（小一号）    │  │  ← 写了 sentences 才有这一块
└──────────────────────────────────────┴──┘
```

- 字号（640 宽下）：单词 60（长句自动降号）｜变形小字 30 ｜词性+释义 28
  ｜短语 26 ｜例句 26 ｜译文 22（**不再有「短语」「例句」标签文字**，以分隔线分区）
- 区块间距：上下约 8–14px、行距 1.15–1.2（v0.5 再收紧）
- 右侧色条宽 = 640 × 2.2% ≈ 14px，颜色 #668D82
- **缩放规则**：宽度 = 640 × k 等比缩放（k 默认按屏宽自动：屏宽 ÷ 1920，档位 0.8 / 1.0 / 1.25 / 1.5），控制面板可手调
- **溢出规则**：超上限自动降一档字号；仍溢出 → 末尾加「…」截断

## 四、内容上限（建议值）

| 区 | 上限（超了会降档缩字，不丢内容） |
|---|---|
| 释义 `senses` | ≤ 3 行，每行 ≤ 24 字 |
| 短语 `phrases` | ≤ 3 条（英文 ≤ 24 字符，中文 ≤ 16 字） |
| 句子 `sentences` | ≤ 2 条（英文 ≤ 50 字符，中文 ≤ 32 字） |

## 五、拍板记录

1. 空区块 → **未定义即省略、高度随内容收**（v0.4 起；紧凑优先）
2. 旧 TXT → **过渡期双支持，JSON 为主**（定稿后可废除 TXT）
3. 内容上限 → 见第四节，**程序自动降档/截断**
4. 字段键 → **全英文**（便于生成器与校验）

## 六、导入与追加

- 控制面板提供「导入词表」：选择一个 JSON → 与现有词表**合并**
  - 相同 `word`（不区分大小写）→ 以新导入内容为准**更新**
  - 其余 → **追加**到末尾
- 给老师 / 老师 AI 的配套文件：`skill-词表生成.md`（发给任意 AI 即可产出合规词表）

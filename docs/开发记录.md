### 1.1 做完的事

| 策略 | 四格统计＋三段分组「正在生效/还没开始/已经结束」；行内两行结构（词+日期段+开关+箭头 / 来源+隐藏标签） | 「已经结束」默认收起；开关 = 永久关闭这一条 |

**第一行「词+日期段」任何情况下不许被截断或重叠**（宽度不够先让右侧标签让位，最后才截词）。

策略开关 → `toggle_strategy`（写 `状态.json`；状态文件坏则拒写）；「按今日/手动展示」→ `set_screen_auto`；

「保存设置」→ 底栏提示；「重播动画」→ 每张卡错峰重播。面板本身不参与穿透（恢复通道只有它）。

### 2.6 验收后修的四件事（真机反馈）

1. **滚动条盖住内容**：egui 默认 floating 滚动条浮在内容上；且 `foreground_color=true` 让滑块取正文色（白面板上一条黑条）。
   修法：`all_styles_mut` 里 `floating=false`、`foreground_color=false`、bar 8px/handle 28px，轨道=面板底色、滑块走 `bg_fill`。
2. **卡片动画变卡（抢帧）**：同一进程内所有 viewport 同趟渲染；面板在动画期间 `request_repaint()` 把它自己拉进全速、
   拖慢卡片。修法：面板固定节流 + 卡片动画只由各自视口 `request_repaint_of` 驱动。实测 1.328s → 0.438s（4s 采样）。
3. **策略行第二行标签「像下一个元素的」**：标签原在第二行居中，距上下行几乎等距（40:40）→ 贴回本行下缘
   （32:49）并把高亮/点击区扩到整行。像素竖扫取证据（分隔线 80px、chip 中心 539、标签中心 571、整行底色一致）。
4. **入场动画只有 29fps**：根因是 `[profile.dev]` 零优化（每帧 34.5ms）。修法：`[profile.dev] opt-level=1` +
   `[profile.dev.package."*"] opt-level=3`；新增 vsync 设置项（在 `opts.glow_options.vsync`，没有 `NativeOptions::vsync`）。
   实测：29.0 → 118.3 fps（debug）；关 vsync 177.1 fps。天花板 = 卡片所在屏刷新率。

### 2.7 层级与穿透解耦（2026-10-02，慕言要求）

原设计两者绑两档；改为**各自独立、四种组合可选**。`config.rs` 本就两个字段（无需迁移，老键 `always_on_top` 迁移保留）；
设置页拆两组二选一；`layer_pair` 删除换成 `set_level`/`set_passthrough`；`top_changed` 改名 `style_changed`；
映射收进 `window::level_of()`。顺带：单实例名在 `cfg(test)` 下加 `.test` 后缀（否则开着 app 跑测试假红）。

### 2.8 没验到的（留给后面）

触摸真机手势；屏缩放≠100% 与多屏；重播动画逐帧确认；置顶真的盖住 PPT 全屏；策略 >8 条时的滚动。

## 3 P3 · 托盘 / 自启 / 单实例 / 关于（2026-10-02）

**范围**：托盘驻留 + 关闭行为、开机自启、单实例、关于页。方案见 `docs/P3-实施方案.md`。

### 3.1 托盘驻留

- 图标：雾青圆角方块+白「L」逐像素画；tooltip；左键=显隐面板，右键=自绘菜单（显/隐面板、显/隐全部卡片、退出）。
- 关闭行为：默认「驻留托盘」（✕ = 面板收进托盘，卡片留桌面）；可切「直接退出」（5 秒二次确认）。
- 真退出三条路（`exiting` 标记绕过关闭拦截）：面板「退出」/ 托盘菜单「退出」/ exit 模式点两次 ✕。
- 托盘建不起来时自动退回「关闭 = 退出」，不会锁死自己。

**两个系统级模态决策**：

1. **「收进托盘」= 挪到 (-32000,-32000)，不能隐藏窗口**：eframe 0.36 对不可见/最小化窗口走直接补画旁路（修 egui#5229），
   那条路没登记事件循环上下文，「新建窗口」（新词卡上屏/托盘显示全部卡片）会被静默跳过 → egui 断言崩。
   实测复现 + 定位（`NO current event loop context`）后改为屏外停放；窗口仍是「可见」态，所有帧走正常路径。
2. **托盘右键菜单弃用系统原生、改自绘**：muda 原生菜单走 `TrackPopupMenu` 模态循环，点完菜单项主循环会「冻住」
   （CPU 0%、一帧不跑、连 WM_CLOSE 都不派发）；唤醒与不唤醒两难（7/7 挂 vs ~1/2 概率幽灵菜单）。
   改为自绘即时视口（`menu.rs`），两轮 ×7 次交互 0 卡死。心跳（250ms，怀疑冻住补一发假鼠标移动）保留为通用保险。

### 3.2 面板复审修复（真机反馈）

- **托盘隐藏后卡片变小跑位**：面板挪屏外后系统把它算成「最近的」左屏（系数 1.0→0.75）。
  修法：屏幕尺寸「面板可见读实时值并记住，收托盘用记住的」。验证：隐藏后 448×309 @(1444,34) 稳定。
- **顶栏 ✕/最小化悬浮闪灰**：淡入用 `mix(TRANSPARENT, 色, t)` alpha 被双重插值。修法：`gamma_multiply(t)`。
  同点位采样 `BCBDBD→D1D2D2→F9FAFB` 变 `F5F7F8→F8F9FA→F9FAFB`。

### 3.3 自启（P3b）

设置开关**不缓存状态**：每次进设置页现读注册表；写 `HKCU\...\Run`（免管理员）。
三种状态：开（值=当前 exe）/未开/**指向旧位置**（面板给「重写为当前位置」按钮）。
实测：开→注册表出现、外改值→显示旧位置+重写、关→条目消失、程序退出不自己加回。

### 3.4 单实例（P3c）

`Local\` 命名互斥体；第二个实例不抢前台（`AllowSetForegroundWindow` 让出许可 + 触发命名事件后自退）；
第一个实例收到事件自己唤回。实测：可见时二次启动进程数不变；收托盘后二次启动面板从屏外回到 (60,360)。

### 3.5 关于（P3d）

### 3.6 任务栏与托盘图标的连环修复

- **收托盘后任务栏按钮还在**：窗口仍「可见」+ winit 默认 `WS_EX_APPWINDOW` → 置 `WS_EX_TOOLWINDOW`、
  清 APPWINDOW，改完必须 `SetWindowPos(SWP_FRAMECHANGED)`。实现 `window::set_taskbar_visible`，位运算纯函数+单测。
- **卡片也一直挂在任务栏**：`with_taskbar(false)` 实测不生效（根因后来查清：映射到 winit `with_skip_taskbar`
  走 `ITaskbarList::DeleteTab` 且时机在置可见之前；不是「eframe 没实现」——2026-10-17 评审更正，见 §5.4）。
  修法：每帧廉价自查（`taskbar_visible` 读样式，不对才写），窗口重建也能纠回。
- **托盘图标连环问题**：①「没留在托盘」——外壳 `E_FAIL`+注册表无条目 = `NIM_ADD` 瞬时失败而旧代码失败不重试
  → 改前 5 次每 2s、之后每分钟重试；②「换个目录就正常」——A/B 对照证明**按 exe 路径静默丢弃**（项目树内一律不出，
  具体条件未查明）→ 不猜原因，建完**回问外壳一次**（`Shell_NotifyIconGetRect` 扫 uID），确认才报「已就绪」，
  查不到就丢图标走重试。单测 78 通过。
- 验证时踩过的坑：滚面板用 `PostMessageW(WM_MOUSEWHEEL)`；debug exe 用 WMI `Win32_Process.Create` 起进程。

## 5 后续维护

### 5.1 教室触屏修复（2026-10-10/11，PR #6 → master `b141631`）

教室一体机（触摸屏）实测反馈三件，两个根因修掉：

- **面板/卡片触摸拖不动**：系统 `ViewportCommand::StartDrag` 落成 `WM_NCLBUTTONDOWN` 模态循环、只认物理鼠标。
  修法：触摸拖动改自己移动窗口；**坐标原子源 = 触摸消息自带的屏幕坐标**（`SetWindowSubclass` 钩子，
  双通路 `WM_TOUCH`→`GetTouchInputInfo` 与 `WM_POINTER`→`GetPointerInfo`；本机走 WM_POINTER）。
  不用 `GetCursorPos`（与窗口移动自激振荡，实测证伪）。
- **穿透时触摸漏不到 PPT**：微软文档明确 `WM_TOUCH` 不认 `HTTRANSPARENT` → 穿透卡片 `UnregisterTouchWindow`
  （每帧幂等 `ensure_touch_state`）。实测穿透卡片 `is_touch_window=False`。
- 第三个反馈（托盘长按）开发机无法复现，判定环境相关。

修法经**子 agent 隔离克隆验收**（A 项 FAIL——调试前缀残留——返工 `dd01f9f` 后合并；B–G 全 PASS）。
`cargo test` 81 通过。已知遗留：多指/鼠标+触屏同时的边缘情况（低危，记录未修）。

**排版收紧（PR #7，待慕言看图确认）**：行距 1.32→1.12 倍 + 条间距收紧；卡片高 301→261px；无切字。

### 5.2 性能优化（2026-10-11，PR #9）

空闲开销三件套，全部实测：

| 场景 | 之前 | 现在 |
|---|---|---|
| 2 卡片课堂常态 CPU | ~10% | ~1.8% |
| 6510 词大词库面板 CPU | ~42% | ~3.1% |
| 常态内存（面板挂着） | 146 MB | ~128 MB |
| 收进托盘后内存 | ~146 MB | ~9 MB（EmptyWorkingSet） |

根因与改动：① 托盘心跳 250ms→1s（每拍一次全量重绘是 10% 的主源）；② 词表行缓存（指纹失效）+ 行虚拟化
（`show_viewport` 只画视野内；行高公式与渲染共享并有单测）；③ 收托盘 `EmptyWorkingSet`；④ 面板自身 300ms
定时器与心跳叠加 → 改 2s 慢速兜底。10628 条词库实测加载正常、空闲 1.95%。
